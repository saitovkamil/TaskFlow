# TaskFlow

TaskFlow - простое веб-приложение для управления повседневными задачами.

## Возможности

- Добавление, редактирование и удаление задач.
- Отметка задач как выполненных.
- Поиск по названию и дате.
- Изменение порядка задач с помощью Drag-and-Drop.
- Сохранение задач в браузере с помощью localStorage.
- Отображение статистики и прогресса выполнения.

## Технологии

- HTML
- CSS
- JavaScript
